JSON Parameter Resolution System

This module provides parameter resolution for jokers that use #N# placeholders in their joker.json text descriptions. It resolves these placeholders to actual numeric values that can be used in joker implementations.

§Architecture

The system loads joker.json and maintains a mapping of joker IDs to their resolved parameter values. This enables joker implementations to use configurable parameters instead of hardcoded values.

§Example

For Half Joker with text "+#1#{} Mult if played hand contains #2#{} or fewer cards", this resolves to parameters: [20, 4] representing 20 mult and 4 cards.
