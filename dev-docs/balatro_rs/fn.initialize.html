pub fn initialize() -> Result<(), Box<dyn Error + Send + Sync>>
Expand description

Initialize all core library systems

This function should be called once during application startup to ensure all factory systems, registries, and global state are properly initialized.

§Errors

Returns an error if any initialization step fails. The application should not continue if initialization fails as it indicates fundamental system issues.
